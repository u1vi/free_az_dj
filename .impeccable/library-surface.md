# Music Library

Mode: Operate. Milestone 2 extends the established plain, practical interface.
Use the existing light surfaces, green accent, system sans, and flat separated
rows. No new visual world, imagery, or display typography is needed.

The default view imports local audio or video through a multiple-file picker
or a drop zone, then displays durable background progress in the Library.
Search, inline title editing, preview playback, removal, and failed-import
retry must work. Keep Setup accessible without stopping shared import state.
The header's Add music action is always available outside an active upload;
background conversion never locks it. This persistent entry point must remain
when milestone 4 introduces trimming and arranging.

The right column previews an actual selected song with native audio controls.
Future YouTube, editing, and export functionality is identified honestly.
Cover loading, empty, filtered-empty, ready, failed, uploading, importing, and
connection-error states. Verify desktop widths 1024px and 1440px; a mobile
layout is explicitly outside the build plan.

Signature behavior: add more files without leaving the workspace, changing
panels, or losing existing tracks. Failed files do not block other imports;
retry reads their saved originals. All waveform and audio processing happens
on the backend. The browser only uploads and plays audio.
