# Setup surface

Mode: Operate. Scope: milestone 1 only; this is a precise dependency screen,
not a full editor or a visual identity exercise.

The user confirmed a plain, practical interface. Build directly in React.
No imagery, promotional content, web fonts, or invented music data is needed.

The first viewport must show the product name, setup purpose, a real dependency
summary, all four tools and their versions, and a Check again button. A quiet
right column explains the future workflow with explicit milestone labels.
Missing tools use readable red text and a named status, never color alone.
Loading, fetch failure, missing tools, and all-ready states must be usable.

Use light neutral surfaces, a restrained green accent, standard sans typography,
flat separated rows, and tabular version numbers. Desktop is the shipped device
class; the build plan explicitly excludes a mobile layout. Verify 1024px and
1440px desktop widths. No standing workflow default is implied.

Signature interaction: Check again refreshes the actual local dependency status
without navigating away; the button is disabled while a request is pending and
the result is announced through a polite live region.
